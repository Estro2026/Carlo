# Bortolotti — Landing Page Build Documentation

## Overview

Create a premium high-conversion landing page for:

**Studio Legale Bortolotti**  
Service: **AgiLex**

The page must communicate:

- premium positioning
- legal authority
- operational reliability
- modern business-oriented consultancy
- accessibility
- trust
- continuity
- elegance
- contemporary corporate aesthetic

The design language must feel:

- editorial
- luxury corporate
- minimal but impactful
- legal-tech inspired
- high-end Italian professional services

Avoid generic "law firm template" aesthetics.

---

# Visual Identity

## Logo

Use:
- Main horizontal logo
- White version on dark backgrounds
- Respect logo clear space
- Never distort logo proportions

---

# Brand Style Direction

The visual direction combines:

- luxury editorial design
